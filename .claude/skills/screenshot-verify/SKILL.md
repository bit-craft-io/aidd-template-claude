## いつ委譲するか

以下のいずれかに該当する時、`screenshot-verifier` agent へ委譲する:

- UIの実装・修正の後、見た目が期待通りか確認したい
- 自動テスト(ピクセル差分・スナップショット等)が失敗し、目視での判断が要る
- 複数の画面・状態を連続して確認する必要があり、本流に画像を何枚も持ち込
  むと文脈が肥大化する恐れがある

## いつ委譲しないか

- 確認対象が一枚限りで、かつこの後の会話でその画像に繰り返し言及する予定
  が無い軽微な確認(委譲のオーバーヘッドの方が上回る)
- 画像ではなくDOM構造・ログ・テキスト出力の確認で足りる場合(そもそも
  画像を見る必要が無い)

## 呼び出し方

```
Agent({
  subagent_type: "screenshot-verifier",
  description: "<確認内容の短い説明>",
  prompt: "<起動手順> にてアプリを立ち上げ、<期待される見た目・状態> と
           一致するか確認せよ"
})
```

agent自体の制約(画像を最終報告に含めない等)は agent定義側で担保済み。
この skill は「委譲すべきか否かの判断」のみを担う。
