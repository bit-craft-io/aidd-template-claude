# Jira の運用

チケット操作は `/jira` スキルを使う(作業の実行は `/jira-exec`)。このファイルには、対象のプロジェクトと、振り分けの基準を書く。ボードの ID や、遷移の ID など、Jira で観察した設定は、`jira` スキルの設定メモに書く。

## 対象

- サイト: `bit-craft.atlassian.net`
- 課題タイプ: `タスク` / `エピック`
- `AIDDS`(名前 aidd-scrum): 計画(`docs/superpowers/plans/` の実装計画)のタスクの登録先。バックログに追加する。「現在のスプリント」もこちら
- `AIDDK`(名前 aidd-kanban): カンバンのタスクの登録先。バックログに追加する
- `HUDDK`(名前 hudd-kanban): 人が行う作業のタスクの登録先。スプリントを使わない、純粋なカンバン。`/jira-exec` の対象外(AI は実行しない)。対象として、明示されたときだけ使う

## 振り分けの基準

「タスクにして」とだけ言われた場合(`HUDDK` は、この振り分けの候補に入れない。人が行う作業のタスクは、`対象: HUDDK` と、明示されたときだけ作る):

- 実装中(スプリント中)に見つけたもので、現在のスプリントの内容と依存関係があるもの → `AIDDS`
- 依存関係がなく、後からでも対応できるもの → `AIDDK`
- どちらか判断できない場合は、作成前に確認する
