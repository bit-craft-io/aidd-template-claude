# 複数プロジェクト同居をやめ、コピー方式の単一ひな形にする

> **遡及作成(2026-10-08)**: 本書は、決定の後に、履歴とCLAUDE.mdの本文から書き起こした。当時の検討過程は記録に残っておらず、判断の理由のうち出典で確認できないものは「要確認」と記す。

## 背景・課題

以前のリポジトリは、`projects/<name>/` の下に複数のプロジェクトを同居させる構成で、`new-project` スキルが新規プロジェクトの雛形を作っていた。この構成を続けなかった理由は、履歴に記されていない(要確認)。

## 決定

リポジトリは、単一プロジェクト用のひな形とする。使うときは、コピーして新しいプロジェクトを作り、以後はそのプロジェクトの持ち物として育てる。

- `projects/<name>/` と `new-project` スキルを廃止する
- コピー元の `.git` は引き継がず、`git init` し直す
- どの時点のひな形からコピーしたかは、`.claude/TEMPLATE_VERSION` に記す
- ひな形の更新は、コピーしたプロジェクトへ自動では届かない

## 検討した代替案

要確認(記録なし)。比較対象として、廃止した複数プロジェクト同居の構成がある。

## 影響・トレードオフ

- ひな形に後から加えた改善は、既存のプロジェクトへ自動では届かない。取り込むには、`TEMPLATE_VERSION` を手掛かりに、手作業で差分を移す必要がある(CLAUDE.md の記述より)
- プロジェクトごとに独立した git リポジトリになる
