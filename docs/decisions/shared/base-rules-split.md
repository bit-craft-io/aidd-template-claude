# 共通ルールを base-rules.md に分け、追記しない

> **遡及作成(2026-10-08)**: 本書は、決定の後に、履歴とルールの本文から書き起こした。当時の検討過程は記録に残っておらず、判断の理由のうち出典で確認できないものは「要確認」と記す。

## 背景・課題

Jira・ドキュメント運用などの共通ルールが、CLAUDE.md に書かれていた。これを分ける理由は、コミットメッセージに記されていない(要確認)。分けた結果として、ひな形から引き継ぐ絶対ルールと、プロジェクト独自のルールが、別のファイルになった。

## 決定

- ひな形から引き継ぐ絶対ルール(Jira・ドキュメント運用・ブランチ運用)は、`.claude/rules/base-rules.md` に置く
- `base-rules.md` には追記しない。ひな形の更新時にのみ差し替える
- プロジェクト独自のルールは、`.claude/rules/` に別ファイルを追加して書く

## 検討した代替案

要確認(記録なし)。

## 影響・トレードオフ

- ひな形の更新を取り込むとき、`base-rules.md` を丸ごと差し替えられる。独自ルールは別ファイルゆえ、巻き込まれない(`base-rules.md` 冒頭の記述より)
- 共通ルールの修正は、ひな形側で行う必要がある。プロジェクト側で直すと、差し替え時に失われる
